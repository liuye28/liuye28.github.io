# 个人导航与开发者/跨境工具箱 (Ly's Workspace)

一个基于 **Vite + React** 构建的轻量、简洁、高效的个人常用网站导航与开发者/跨境电商运营工具箱。全面采用 **Apple (macOS / iOS / HIG)** 极简美学设计，支持深浅色模式自由切换、实时搜索与过滤、多工具独立路由，并支持通过 GitHub Actions 自动构建部署至 GitHub Pages。

---

## 🌟 特性一览

### 🧭 网站导航
- ⚡ **轻量疾速**：基于 Vite + React，通过 `React.lazy` 与 `Suspense` 实现路由按需拆包 (Code Splitting)，首页初始加载秒开。
- 🎨 **Apple 美学**：留白舒适、SF Pro 字体体系、App 图标圆角与微交互动效。
- 🌓 **深浅外观**：智能跟随系统偏好，HTML 头部注入防闪烁初始化脚本彻底告别刷新白屏跳闪 (FOUC)，支持一键切换与本地记忆。
- 🔍 **Spotlight 搜索**：支持 `⌘K` / `Ctrl+K` 快速聚焦，支持名称、描述、网址/域名（如 zhihu、juejin）全局模糊匹配，支持按 `Enter` 回车直达。
- 🏷️ **iOS 分段控制器**：分类切换带计数微标与浮动胶囊背景。
- 🌐 **自动 Favicon**：基于国内稳定高速的 `favicon.im` 服务动态获取高清图标，并提供优雅首字母 Fallback。

---

### 🛠️ 实用工具箱 (9 款全开箱即用，支持分类检索与独立路由)

#### 📦 跨境电商专区 (Ozon 平台刊登辅助)
- 📄 **Ozon 富内容生成器 (`#/tools/ozon-rich`)**：
  - **精准识别 4 大核心卖点**：内置核心大标题白名单（`Дизайн и концепция:`、`Посадка и тепло:`、`С чем сочетать:`、`Идеи для стилизации:`、`Назначение:` 等），智能排除列表子项（`◦`、`。`、`•`、`-`）内部冒号干扰。
  - **100% 官方规范对齐**：支持跨行正文与多段换行自动转换 Ozon 官方 `{"type": "br"}` 换行结构，输出官方标准 `raTextBlock` JSON (`version: 0.3`)。
  - **可视化微调与实时响应**：支持区块实时增删与文本编辑，右侧 JSON 实时秒级响应，支持一键复制。

- 📊 **Ozon 尺码表生成器 (`#/tools/ozon-size`)**：
  - **中文全自动净化**：自动清洗工厂尺寸表中的中文注释（如 `(衣长)`、`（胸围）`、`(夹对夹度量)`），自动标准化为 Ozon 官方纯俄文参数（`Длина спереди, см`、`Ширина горловины, см`、`Ширина плеч, см`、`Обхват груди, см`、`Глубина проймы по прямой, см`、`Длина рукава, см`、`Обхват по низу изделия, см` 等）。
  - **RU + INT 双尺码行自动生成**：输入国际码（`S, M, L, XL`）时，自动补齐对应的俄罗斯尺码（`44, 46, 48, 50`）生成双行对照表头。
  - **智能 4 尺码优选过滤**：基于业务优先级优先提取 `M~XXL`（或 `S~XL`）4 个核心尺码，避免多余列冗余。
  - **多源格式自适应**：支持从 Excel/WPS 直接复制粘贴，智能兼容制表符 Tab、`|` 竖线、连续空格或逗号。
  - **HTML 表格实时可视化预览**：在页面下方实时渲染标准预览表格，输出符合 Ozon 官方规范的 `tcTable` JSON (`version: 0.1`)。

#### 💻 开发与调试工具
- 📝 **代码练习板 (`#/tools/code-pad`)**：
  - **Monaco Editor 强力驱动**：集成 VS Code 核心编辑器内核，提供原生级代码高亮、语法着色、缩进对齐与快捷键操作体验。
  - **主流语言 LeetCode 模版**：内置 Java (17+)、Python 3、C++ 17、Go (Golang)、JavaScript (ES6)、MySQL/SQL 等经典算法与题型模板，一键切换并秒级载入。
  - **双栏对照 & 沉浸式全屏 (Zen Mode)**：左侧支持题目要求/用例/草稿笔记编辑，右侧手敲代码，支持单双栏一键切换与 Esc 沉浸全屏模式。
  - **多主题与个性化配置**：支持默认自动跟随全站外观（Auto）、清爽浅色、深色暗黑 (LeetCode Dark)、高对比度等定制主题，支持字号无级缩放 (A-/A+)、Minimap 小地图开关与一键格式化 (Format Document)。
  - **多语言独立防丢持久化**：各编程语言代码草稿独立持久化存储至本地，切换语言绝不冲掉已写代码；页面刷新或重开不丢失进度，实时显示行数与字符数统计。

- ⏱️ **时间戳转换器 (`#/tools/timestamp`)**：
  - 支持秒（10位）与毫秒（13位）自动识别，双向转换为本地时间、**莫斯科时间 (MSK / UTC+3，契合 Ozon 业务时区)**、相对时间（刚刚、5分钟前）、UTC 与 ISO 8601 格式。
  - 支持每秒跳动的实时时间戳展示与暂停/恢复，支持一键填入当前时间。

- 🎯 **正则表达式测试器 (`#/tools/regex`)**：
  - 支持 Flags 修饰符胶囊勾选（`g`, `i`, `m`, `s`）及常用正则预设（邮箱、手机号、网址、IP 等）。
  - 待测文本匹配区域实时背景高亮，结构化展示匹配总数与详细索引列表。

#### 🔄 编码与转换工具
- 📦 **JSON 格式化 / 校验器 (`#/tools/json`)**：
  - 双栏实时排版，2 空格标准缩进美化，支持一键复制与单行压缩（Minify）。
  - 语法错误时底部实时弹出温和报错横幅，精确提示错误行号与位置。

- 🔤 **URL / Base64 编解码器 (`#/tools/codec`)**：
  - 支持 URL 与 Base64 双向编解码，原生支持 UTF-8 中文无乱码，支持一键输入输出互换。

#### 🛡️ 安全与计算工具
- 🔢 **进制转换器 (`#/tools/base-convert`)**：
  - 二进制、八进制、十进制、十六进制实时同步互转，支持 BigInt 大数精度计算。
  - 实时非法字符检测与提示，各进制结果独立一键复制。

- 🔑 **哈希与 UUID 生成器 (`#/tools/hash`)**：
  - 基于 Web Crypto API 实时计算 SHA-256、SHA-512、SHA-1 等哈希值，支持标准 UUID v4 单个及批量定制生成。

## 🛠️ 技术栈

- **构建工具**：Vite 6
- **核心框架**：React 18 (函数组件 + Hooks)
- **代码编辑器**：Monaco Editor (`@monaco-editor/react`)
- **路由方案**：React Router 7 (使用 `HashRouter` 适配 GitHub Pages 静态部署与刷新)
- **样式方案**：纯 CSS (Apple HIG CSS Custom Properties 变量设计系统)
- **持续集成**：GitHub Actions (`.github/workflows/deploy.yml`)

## 🚀 快速上手

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可预览。

### 3. 构建打包
```bash
npm run build
```
打包产物输出至 `dist/` 目录。

---

## 🚢 部署到 GitHub Pages

1. 将代码推送到 GitHub 的 `main` 分支（仓库名 `用户名.github.io`）。
2. 在 GitHub 仓库页面中点击 **Settings** -> **Pages**。
3. 将 **Build and deployment** 下的 **Source** 选择为 **GitHub Actions**。
4. 随后推送到 `main` 分支时，GitHub Actions 会自动打包并发布，1~2 分钟后即可通过 `https://<用户名>.github.io` 访问！
